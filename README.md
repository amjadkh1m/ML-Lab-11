# Credit Card Customer Segmentation

## Overview
This project uses K-Means Clustering to group credit card customers based on their spending behavior and account activity.

## Dataset
Dataset used:

CC_GENERAL.csv

The dataset includes features such as balance, purchases, credit limit, and cash advance.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Steps
- Load and clean the data
- Handle missing values
- Scale features using StandardScaler
- Apply K-Means Clustering
- Use Elbow Method and Silhouette Score
- Visualize clusters using PCA

## Clustering
The final number of clusters selected was:

K = 4

## Results
The model grouped customers into different segments based on their usage patterns and spending behavior.
